## Root Cause Summary
- Public debug endpoint leaked credentials
- Privileged workflow modifications allowed after login
- Docker socket exposed to application runtime
- Privileged container creation not restricted

**Net impact:** info leak → account compromise → workflow abuse → host compromise.

---

## Defensive Recommendations
1. Disable or strictly protect debug/health endpoints
2. Restrict n8n admin/API network exposure
3. Never mount Docker socket into app containers
4. Block privileged container creation in production
5. Enforce least privilege and runtime isolation
