## 7) Root Cause (3lach t9edr exploit)

- command composition unsafe
- no strict allowlist

## 8) Kifach يتصلح

3. Dir allowlist strict l `benchmark` values.
4. Khddem service b user ma-شي root.
5. Zid runtime restrictions (seccomp/apparmor).
6. Reject metacharacters and dangerous payload patterns.
