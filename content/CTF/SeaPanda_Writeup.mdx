## Q5) Dropped DLL MD5
The DLL is embedded as **resource PAYLOAD_DLL** inside the EXE.

**Command (pefile extract + MD5):**
```bash
python3 - <<'PY'
import pefile, hashlib
pe=pefile.PE('/tmp/vessel_update.exe')
for entry in pe.DIRECTORY_ENTRY_RESOURCE.entries:
    name = entry.name if entry.name else entry.struct.Id
    if str(name) != '10':
        continue
    for e2 in entry.directory.entries:
        n2 = e2.name if e2.name else e2.struct.Id
        if str(n2) != 'PAYLOAD_DLL':
            continue
        for e3 in e2.directory.entries:
            data_rva = e3.data.struct.OffsetToData
            size = e3.data.struct.Size
            data = pe.get_memory_mapped_image()[data_rva:data_rva+size]
            open('/tmp/payload_dll.bin','wb').write(data)
            print(hashlib.md5(data).hexdigest())
PY
```
**MD5:** `67ddf30eac83bbedc5137ce54ebebadf`
